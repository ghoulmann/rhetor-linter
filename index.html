Problem Clusters

13 clusters · 34+ rules · click any card to drill down
RL · 01
Prose & Rhetoric
Writing that hedges, trivializes, or buries meaning in noun stacks — invisible to syntax linters.
↗
RL · 02
Cohesion & Flow
Sentences that don't connect. Pronouns that point at nothing. Topics that drift from their headings.
↗
RL · 03
Structure & Navigation
Generic headings, missing H1s, and long documents with no navigational scaffold leave readers lost.
↗
RL · 04
Task Completeness
Procedures that end before the verification step. Steps with no error guidance strand readers at the first failure.
↗
RL · 05
Style & Terminology
Non-canonical terms, exclusionary language, and inconsistent phrasing accumulate across a doc set invisibly.
↗
RL · 06
Readability
Sentence rhythm that never varies, nested clauses, and metric-dense sentences exhaust working memory.
↗
RL · 07
JTBD Coverage
A doc set can be internally correct while missing the jobs readers actually bring to it.
↗
RL · 08
Doc Drift from Code
Code that outpaces documentation is the most common form of doc debt — and the least visible until it causes failures.
↗
RL · 09
Vale & markdownlint Compatibility
Org-wide style enforcement requires a rule format teams can write and own. All 10 Vale rule types, plus markdownlint-cli2 Python custom rules.
↗
RL · 10
Currency
Version numbers, deprecated flags, and stale last-reviewed dates compound silently with no automated signal.
↗
RL · 11
Relevance
A beginner page written at expert level, or a reference doc that reads like a tutorial, misroutes its reader before they've read a sentence.
↗
RL · 12
Completion
The most expensive gap is the doc that doesn't exist. API endpoints, config keys, user journeys — invisible to any per-file linter.
↗
RL · 13
Compliance
ADRs without a Decision section, ordered lists that skip imperatives, heading levels that jump — violations of standards that exist to make docs predictable.
↗

Install & Run

pip · pipenv · virtualenv
Install
# pipenv
make pipenv && pipenv shell

# virtualenv
make virtualenv
source .venv/bin/activate

# optional: spell checking
pip install 'rhetoric-lint[spell]'
Pre-commit hook
# .pre-commit-config.yaml
repos:
  - repo: local
    hooks:
      - id: rhetoric-lint
        name: rhetoric-lint
        entry: rhetoric-lint
        args: [--min-severity, warning]
        language: python
        types: [markdown]
Usage
# lint a directory
rhetoric-lint docs/

# with Vale style rules
rhetoric-lint \
  --style-dir style-sets/ \
  --style Rhetoric,Clarity \
  docs/

# apply deterministic fixes
rhetoric-lint --fix docs/

# list all rules
rhetoric-lint rules

# with JTBD manifest
rhetoric-lint \
  --jtbd-manifest jobs.yaml \
  docs/

# override genre detection
rhetoric-lint --genre howto docs/
